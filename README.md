# Moonlander

Eine Mondlandesimulation
------------------------

Das Mondlandeprogramm war das allererste Programm, das ich benutzt habe, als ich
1980 zum ersten Mal einen Computer (Commodore PET) verwendete. Damals wollte ich
unbedingt wissen,  wie das funktioniert  und habe sofort entsprechende  Kurse in
der Schule belegt. Natürlich habe ich auch für  den alten PET in Basic schon mal
eine Mondlandesimulation implementiert.

Jetzt  fast  50  Jahre  später  habe  ich nun  eine  neue  Version  in  C++  für
Windows-Rechner implementiert.

Es   ist   natürlich   keine   richtige  Simulation.   Vor   allen   fehlt   die
Berücksichtigung, dass die Landefähre beim Bremsen auch leichter wird.

Den Treibstoffvorat,-verbrauch  und die  maximale Landegeschwindigkeit  habe ich
willkürlich festgelegt. Der Spielspaß liegt natürlich im Vordergrund.

Die Benutzung ist sehr einfach. Das Programm  kann mit ein paar Tasten gesteuert
werden:

'0'-'9': Steuerung der Bremsraketen.
'R':     Neustart der Mission
'E':     Zeigt zusätzliche Metriken:
         Zeit bis zur Landung
         Geschwindigkeit bei der Landung
'Q':     Beendet das Programm.
